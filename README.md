# Лабораторная работа
Обработка числовых матриц

## Автор
Бакаанова Ляна (Вариант 1)

## Цель
Освоение базового синтаксиса C++, работы с двумерными массивами (матрицами) и организации циклов для обработки числовых данных.

## Описание
Программа вычисляет сумму положительных элементов для каждого столбца заданной матрицы. Исходная матрица выводится в общепринятом виде, после чего результаты выводятся в виде двух строк: в первой – номера столбцов, во второй – соответствующие суммы.
